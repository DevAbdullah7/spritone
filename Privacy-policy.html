Privacy Policy

سياسة الخصوصية

Last Updated: October 15, 2026

This Privacy Policy ('Policy') explains how data and information are handled when using the Spritone tool and website ('we,' 'our,' or the 'Tool'). We are committed to the highest standards of privacy protection and digital security. Because the Spritone tool operates entirely within the user's web browser (Client-side), our fundamental principle is not to collect, store, or share any personal data or private files belonging to the user.

اخر تحديث: October 15, 2026

تُوضح سياسة الخصوصية هذه ("السياسة") كيفية التعامل مع البيانات والمعلومات عند استخدام الأداة وموقع Spritone ("نحن"، "الخاص بنا"، أو "الأداة"). نحن نلتزم بأعلى معايير حماية الخصوصية والأمان الرقمي. نظرًا لأن أداة Spritone تعمل بالكامل في متصفح الانترنت الخاص بالمستخدم (Client-side)، فإن مبدأنا الأساسي هو عدم جمع أو تخزين أو مشاركة أي بيانات شخصية أو ملفات خاصة بالمستخدم.

1. Uploaded Files:

1. الملفات المرفوعة:

A أ .

All SVG files, vector graphics, icons, and source code uploaded, edited, or processed through the Tool are processed locally and exclusively within the Random Access Memory (RAM) of the user's web browser.

جميع ملفات الـ SVG، والرسوم المتجهة، والأيقونات، والأكواد المصدريّة التي يتم رفعها أو تحريرها أو معالجتها عبر الأداة تُعالج محلياً وبشكل حصري داخل ذاكرة الوصول المؤقتة (RAM) لمتصفح الانترنت الخاص بالمستخدم.

B ب .

The Tool does not upload, transmit, copy, or store any files or graphic assets to any external servers or databases. Files remain completely confined within the user's device and web browser session.

لا تقوم الأداة برفع، أو نقل، أو نسخ، أو تخزين أي من الملفات أو الأصول الرسومية إلى أي خوادم (Servers) أو قواعد بيانات خارجية. تظل الملفات محصورة بالكامل داخل جهاز وجلسة متصفح الانترنت الخاص بالمستخدم.

2. Data Collection:

2. جمع البيانات:

We do not collect or transmit any of the following types of data:

نحن لا نجمع ولا ننقل أي نوع من البيانات التالية:

A أ .

Personal Identifiable Information (PII): Such as name, email address (unless you voluntarily contact us for support), phone number, or physical address.

بيانات الهوية الشخصية: مثل الاسم، البريد الإلكتروني (ما لم تتواصل معنا طوعاً للدعم)، رقم الهاتف، أو العنوان.

B ب .

File and Asset Contents: We do not inspect, view, or retain any SVG files or code outputs generated using the Tool.

محتوى الملفات والأصول: لا نستطلع، أو نطلّع على، أو نحتفظ بأي ملفات SVG أو مخرجات برمجية تم توليدها باستخدام الأداة.

3. Privacy and Files Processing:

3. خصوصية ومعالجة الملفات:

A أ .

Files Privacy: The Service does not upload, transmit, collect, or store any files, source code, or metadata on any external servers or databases. All source files and code remain completely confined within the user's web browser session.

خصوصية الملفات: لا تقوم الخدمة برفع أي ملفات أو رموز برمجية (كود) أو بيانات وصفية، ولا تنقلها أو تجمعها أو تخزنها على أي خوادم أو قواعد بيانات خارجية. تظل جميع الملفات المصدرية والرموز البرمجية محصورة بالكامل ضمن جلسة متصفح الانترنت الخاص بالمستخدم.

B ب .

Exclusive Local Processing: All compilation, compression, code cleaning, Sprite generation, and file exporting operations occur locally within the Random Access Memory (RAM) of the user's web browser.

معالجة الملفات: تتم جميع عمليات التجميع، والضغط، وتنظيف الكود، وإنشاء العناصر الرسومية (Sprites)، وتصدير الملفات محلياً داخل الذاكرة المؤقتة (RAM) لمتصفح الانترنت الخاص بالمستخدم.

4. Cookies and Local Storage:

4. ملفات تعريف الارتباط:

A أ .

Cookies: The Tool does not use any cookies for tracking, identifying users, or targeting advertisements.

ملفات تعريف الارتباط: لا تستخدم الأداة أي ملفات تعريف ارتباط (Cookies) للتتبع أو لتحديد هوية المستخدمين أو لاستهداف الإعلانات.

B ب .

Local Storage: Browser Local Storage technology may be used exclusively to save the user's preference settings within the Tool (such as theme or language) locally on the web browser, and these can be cleared at any time via the browser settings.

التخزين المحلي (Local Storage): قد تُستخدم تقنية التخزين المحلي لمتصفح الانترنت (Browser Local Storage) حصرياً لحفظ تفضيلات الإعدادات الخاصة بالمستخدم داخل الأداة (مثل المظهر، أو اللغة) محلياً على متصفح الانترنت، ويمكن مسحها في أي وقت عبر إعدادات المتصفح.

5. Hosting Services and Third-Party Analytics:

5. خدمات الاستضافة والتحليلات الخارجية:

A أ .

In the event that any static hosting services (such as GitHub Pages, Vercel, or Cloudflare) are used to serve the website's static files (HTML/CSS/JS), these platforms may record standard server logs containing IP addresses and browser types solely for network security and service stability purposes, without any linking to, access to, or interference with user files or activities within the Tool.

في حال استخدام أي خدمات استضافة ساكنة (Static Hosting) مثل GitHub Pages أو Vercel أو Cloudflare لعرض ملفات الموقع الساكنة (HTML/CSS/JS)، قد تقوم هذه المنصات بتسجيل سجلات خادم قياسية (Standard Server Logs) تتضمن عنوان الـ IP ونوع المتصفح لأغراض حماية الشبكة واستقرار الخدمة فقط، دون أي ربط أو وصول أو مساس بملفات أو نشاط المستخدمين داخل الأداة.

A ب .

We use Google Analytics to collect general statistical information regarding how users interact with the website (such as: the duration of a user's stay on the page, buttons or features used, geographic location, preferred language, and device used) to analyze user behavior when using the website, for the purpose of improving website performance and developing the user experience (UI/UX). Furthermore, we affirm that the use of Google Analytics does not, under any circumstances, include or access the files, vector graphics (SVG), or code/symbols (Sprites) that the user processes locally within the Random Access Memory (RAM) of the user's web browser.

نستخدم أداة Google Analytics لجمع معلومات إحصائية عامة حول كيفية تفاعل المستخدمين مع الموقع (مثل: مدة بقاء المستخدم في الصفحة، الأزرار أو الوظائف المستخدمة، والموقع الجغرافي واللغة المفضلة والجهاز المُستخدم). لتحليل سلوك المستخدمين عند استخدام الموقع، وذلك بغرض تحسين أداء الموقع وتطوير تجربة المستخدم (UI/UX)، كما نؤكد أن استخدام Google Analytics لا يشمل أو يصل بأي حال من الأحوال إلى الملفات، أو الرسومات المتجهة (SVG)، أو الرموز البرمجية (Sprites) التي يقوم المستخدم بمعالجتها محلياً في الذاكرة المؤقتة (RAM) لمتصفح الانترنت الخاص بالمستخدم.
